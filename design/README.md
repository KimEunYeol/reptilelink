# 디자인 원본과 탐색

이 폴더는 렙타일링크의 유일한 시각 기준이다. 사용자가 제공한 PNG는 이름과 바이트를 그대로 보존한다. 앱의 `public/`에 통째로 복사하거나 시안의 예시 연락처·사진을 운영 데이터로 게시하지 않는다.

- `렙타일링크_디자인.png`: **전체 보드와 설명 텍스트의 기준**. 개별 export에는 빠진 설명·팝업·상태가 있으므로 함께 확인한다. 20356×13738px이므로 필요 부분을 원본 배율로 확대한다.
- `*-m.png`: 모바일 화면. `*-m-1.png`, `*2-m.png` 등도 상태·팝업 참고 자료이므로 생략하지 않는다.
- 이름에 `-m`이 없는 주 화면: PC 화면. `아이디찾기-m2.png`, `아이디찾기-m3.png`는 별도 단계다.
- `Group *.png`, `Snippets/`: 원본 부분 자산. 실제 이미지를 열어 용도를 확인한다. 이름만으로 로고·상태·버튼 용도를 추측하지 않는다.
- `최하단*.png`: 모바일/PC footer export. 예시 회사 정보는 디자인 자리표시자다.
- `inventory.json`: 모든 원본 PNG의 경로·해상도·바이트 수·SHA-256. `npm run design:check`로 누락/변조/추가를 감지한다. 의도적 원본 변경은 별도 이슈·PR에서 검토하고 `npm run design:inventory`로 갱신한다.

텍스트·상태·저장 동작의 판정 및 예외는 [디자인 계약](../docs/08-design-contract.md)을 따른다. 원본 이미지 안의 텍스트는 자동 OCR로 검증하지 않는다. 화면별 설명의 전사와 구현 비교는 작업 에이전트가 수행하고 기록한다.

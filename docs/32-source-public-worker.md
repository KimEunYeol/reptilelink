## 실제 화면·이동·공유

공개 화면을 PublicPage.tsx로 분리했다. 카드의 실제 이름/성별/종류·모프·설명/댓글 수는 HTML이며, 사진은 기존 공개 이미지 경로에서 읽는다. 기본 실루엣과 초록 면/하단 음영도 원본 패턴이다. 실제 업로드 사진·커버·아바타는 /api/image의 현재 공개 검사와 같은 경로를 JS/Worker 모두 사용한다. 관리 미리보기의 인증 이미지 경로는 유지한다. 공개5개 페이지 규칙만 추가하며 관리 목록10개는 유지한다.

카드 클릭은 실제 /u/slug/animals/UUID로 이동한다. 목록에서 열었으면 닫기/Back은 같은 페이지·스크롤·카드 초점으로 돌아가고, 직접 상세 주소의 닫기는 자신의 목록으로 이동한다. 라우터 이력에는 공개 경로/초점 대상 ID/스크롤만 남기고 임시 댓글이나 토큰을 별도 저장하지 않는다. 조회 전환에서 이전 경로의 결과를 새 결과로 표시하거나 초점을 먼저 복구하지 않도록 완료된 경로 표식을 확인한다. 처음 bootstrap은 한 번 소비하며 이후 실제 경로/페이지 이동은 현재 공개 RPC를 새로 읽는다.

기존 댓글의 dirty/미확인/동일 요청·이동/닫기 보호와 좋아요 pending 보호를 유지한다. 처리 중에는 새 페이지/상세/공유/일정 진입을 잠근다. 별도의 경쟁 router blocker는 추가하지 않았다. 긴 이름은 헤더에서2줄로 줄이고 전체 값은 본문 이름 행에 남겨 닫기·본문 스크롤을 유지한다.

커버 공유는 실제 현재 origin의 공개 root 주소만 사용한다. 지원되는 navigator.share 또는 클립보드로 연결하고 취소/실패를 성공으로 표시하지 않는다. 실패 시 실제 주소를 직접 복사할 수 있게 한다. 실제 브라우저 클립보드 쓰기/읽기를 확인했고 native share 취소/실패 분기는 브라우저 stub로 검증했다. 운영체제 공유 시트나 수신자 전달을 검증한 것은 아니다. 개체 상세 주소 자체도 실제 URL로 공유/재진입할 수 있다.

일정은 원본 회색 요약 행에서340px 읽기 전용 팝업으로 연다. 원본의 상태/제목·시작/종료 한국 날짜와 시간·상세 내용·닫기/초점 패턴을 사용한다. 서버 시각+단조 경과·visibility 복귀 조회의 기존 상태 계산을 유지한다.

원본의 흰 글자/연한 배지를 그대로 두면 임의 사진에서 읽을 수 없는 경우가 있어 같은 색 계열 배지와 더 짙은 하단 음영·검은 반투명 아이콘 배경을 사용했다. 공개 링크는 원본66px 둥근 패턴과84% 본문 폭으로 맞췄다. 실제 사진/설명 길이와 설정된 일정/링크/SNS 개수에 따라 높이는 달라지며 없는 사용자 문구/사진/수치를 채우지 않는다. 기본 커버/프로필은 이전에 승인한 원본 자산·테마이고 시안의 예시 커버 문구를 사용자 소개로 복사하지 않는다.

## Worker 초기 HTML

작은 문자열 템플릿과 공유 포맷/기존 CSS로 같은 순서·폭·카드/상세를 제공한다. React 서버 렌더러나 새 프레임워크/서비스를 추가하지 않았다. 정적 아이콘은 설치된 lucide-react1.62.0(ISC) 출력과 같으며 Worker에 React 렌더러를 넣지 않는다. root는 기존 public_page 한 번, 상세는 최소 공개 성장/댓글 읽기 두 번을 추가한다. 운영 Worker CPU/한도·실제 Cloudflare 배포를 로컬 결과로 보장하지 않는다.

JS 없는 화면에서도 실제 이미지·5개 페이지·상세 링크·닫기와 공개 날짜/성장 기록/댓글을 읽을 수 있다. 상세 배경은 inert이며 원본 모양의 좁은 읽기 영역/실제 링크를 제공한다. 실제 JS native dialog의 초점/행동과 no-JS 정적 영역은 동일한 실행 방식이라고 주장하지 않는다. no-JS 일정은 native details로 읽고 기간 탭/추가 기록·인증/반응/OS 공유 등 앱 조작은 JS가 필요하다. no-JS 공유 아이콘은 실제 공개 주소 링크이며 복사 성공을 가장하지 않는다.

초기 본문/metadata에는 최소 공개 DTO만 사용한다. 사용자 본문/링크/이름은 escape하고 private 메모·Auth UUID/이메일/파일 경로를 넣지 않는다. 상세 제목/설명/이미지는 실제 개체 값, 빈 프로필 설명은 중립적인 페이지 설명이다. 비공개/없는 상세는 동일404/no-store/noindex·bootstrap 없음이며 댓글 조회가 현재 비공개를 확인하면 오래된 페이지를 표시하지 않는다. 상위 공개 RPC 장애는 개인정보/원시 오류 없는 HTML503과 재시도를 제공하며 클라이언트도 없는 페이지와 조회 실패를 구분한다. 실패한 성장/댓글 읽기를 가짜0/빈 결과로 표시하지 않는다.

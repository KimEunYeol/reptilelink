## 저장·권한·복구

## URL·공개 렌더링

브라우저는 WHATWG URL로 대소문자/IDN·IPv4/IPv6·기본포트·경로를 정규화한다. 자격증명(빈 사용자명 포함), 제어문자·역슬래시·잘못된 percent escape/호스트/포트를 거절하며 정규화 결과의 ASCII 길이를 검사한다. DB도 독립 private.valid_https_url CHECK/명령 검증으로 HTTPS·ASCII·호스트/IP·포트·길이·금지문자를 검사한다. 서버는 사용자가 입력한 URL을 fetch하지 않는다.

React/Worker는 공개 링크만 렌더링하고 제목은 텍스트/HTML escape, URL도 검증·escape한다. 색상은 허용 토큰만 사용하며 새 탭은 rel="noopener noreferrer"다. 브라우저 검사는 외부 페이지를 로컬 응답 fixture로 대체해 window.opener=null을 확인한다. 외부 서비스 연결 성공을 테스트했다고 표시하지 않는다.

공식 근거: [WHATWG IPv4 parser](https://url.spec.whatwg.org/#concept-ipv4-parser), [PostgreSQL network types/functions](https://www.postgresql.org/docs/current/functions-net.html). Supabase RLS/현재 변경 이력은 선행 성장 단계에서 확인한 기준을 유지한다.

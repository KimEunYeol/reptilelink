# 원본 메인과 공통 표시 (#37)

삭제대기 탈퇴 PR44/maindf800b7 뒤의 독립 작업이다. 원본 PC1920×3647·모바일450×4191과 전체 보드 메인(0,2800,700,3300)·PC 공통(0,8400,5000,1000)의 설명을 다시 확인했다. 메인만 PC 가로 확장을 사용하며 다른 화면 본문을 넓히지 않았다.

초록 둥근 히어로/휴대폰→개체·댓글→회색 성장→흰 일정→초록 SNS→회색 푸터의 순서·비율·타이포 관계를 구현했다. 제목·설명·주소 형식·로그인/회원가입/본인 관리·정책 링크는 실제 HTML이다. 기존 수제 메인 삽화·장식/Brand를 원본 부분 자산과 공통 SourceBrand/ManagementFooter로 교체했다. 공통 로고 교체는 인증/공개 헤더에도 반영되지만 해당 화면 내부 정비는 #38/#39에서 계속한다. 기존 인증/저장/미확인/공개 동작은 보존했다.

## 자산과 표시 차이

- public/brand/main의11 PNG는 해당 PC/모바일에서 사각형 부분만 원본 픽셀로 추출했다. manifest.json에 원본/결과 SHA256·좌표·바이트를 기록하고 실제 해시를 대조했다. 합계839,010바이트이며 아래 그림은 lazy load하고 picture가 해당 폭의 그림만 선택한다. 원본97PNG는 그대로이며 전체 화면을 이미지 UI로 만들지 않았다.
- 휴대폰·댓글·체중 그래프·일정·SNS 그림은 설명용 예시다. alt/보이는 캡션에서 실제 사용자 후기/집계/행사로 오해하지 않게 구분했다. 시안의 회사/이메일/전화/주소/TEAM770은 반입하지 않았다. 예시 reptilelink.kr 주소 소유권을 추정하지 않고 /u/your-id 형식 예시를 표시한다.
- 원본 ‘평생 무료’/무제한처럼 보일 수 있는 표현 대신 D07 초대·승인 후 기록/공유를 안내한다. 경매/거래 서비스는 추가하지 않고 실제 F06 일정 기능만 설명한다. 무료 회원가입은 실제 Google 진입 화면으로 이어지며 외부 OAuth 연결 전 상태는 기존 안내를 유지한다.
- 실제 원본 초록 픽셀은 rgb49/186/81(#31ba51)이었다. 기존 CSS rgb44/187/80과 구분해 히어로/SNS/기본 버튼을 맞췄다. 부분 그림의 초록/흰 배경 전환은 그림 크기와 같은 비율의 하단 여백으로 맞춰 경계를 피하고, 좁은 폭에서는 제목/패딩과 그림을 함께 조정해 겹침을 막았다.
- 원본의 작은 흰 글자/초록은 대비가 부족하므로 기존 외부 링크에서 채택한 어두운 글자 패턴을 같은 색 계열에서 재사용했다. 일반 버튼/히어로는 약6.0545:1이며 hover도4.5 이상이다. 어두운 버튼의 흰 글자와 Google/회색 버튼 등의 별도 스타일은 유지한다. 푸터 링크/작은 본문은 같은 회색·초록 계열에서 대비를 보완했다. [W3C 글자 대비 기준](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)을 사용하며 시안 예시 그림 속 모든 글자나 전체 WCAG 준수를 선언하지 않는다.
- 정확한 폰트 파일은 제공되지 않았다. 기존 fallback을 유지하고 굵기 합성을 허용해 원본의 일반/강조 관계를 표시한다. 플랫폼별 글꼴/emoji·Native 컨트롤까지 같은 폰트/픽셀이라고 주장하지 않는다. 외부 폰트/브랜드/예시 사진의 배포 권리는 사용자 확인이 필요하다.

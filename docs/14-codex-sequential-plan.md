## 별도로 남겨 둘 항목

Google/Cloudflare/운영 Supabase의 웹 콘솔 조작, 실제 OAuth/원격 배포·도메인·원격 비밀 설정은 사용자 데스크톱 단계다. 로컬 fixture 성공을 운영 검증으로 표시하지 않는다. 실제 법적 문서/운영 연락처/자산 사용 권한처럼 사용자 자료가 필요한 것은 임의로 만들지 않고 필요한 입력과 연결 지점을 인계한다. 해당 입력과 무관한 개발은 계속한다.

추가 지출0원, 기존 스택/단일 에이전트, 기존 사용자 자료 보존을 유지한다. QA는 명시적 테스트 계정/현재 실행 ID로 제한하며 DB 초기화·볼륨 삭제·이전 migration 재적용을 하지 않는다. 긴 작업은 현재 작업 기록과 goal을 유지해 이어가며, 한 단계 보고가 전체 목표 완료를 뜻하지 않는다.

## 초안·응답유실·충돌

세 텍스트와 SNS6행은 하나의 메모리 초안이다. 취소/SPA·전체 문서 이탈 보호와 공개 전환/로그아웃 잠금을 함께 사용한다. 미확인 명령은 정규화한 전체 본문/요청 ID를 보존하고 두 영역을 모두 잠근다. 저장 후 dashboard 또는 실제 디자인 조회가 실패해도 잠금을 풀지 않는다. 취소/최신 확인도 같은 요청의 재확인과 실제 조회가 성공해야 끝난다.

최신 검토는 프로필 텍스트와 SNS를 함께 보여주며 입력을 자동 대체하지 않는다. 입력 복사는 소개/이름/설명·모든 SNS 주소를 포함하고, 명시적 최신 설정 사용으로만 대체한다. 미확인/충돌 중 자동 revision 조회도 초안을 덮지 않는다. 초기 조회 실패에는 저장된 것처럼 보이는 가짜 빈 프로필/목록을 표시하지 않는다. 공개 소개를 지워도 앱이 대신 소개를 창작하지 않는다.

## 원본과 구현

통계알림 PC/m·기본정보-m·메인 PC/m와 보드를 직접 확인했다. 보드 모바일 설명(0,0,3800,650)은 모바일 우선/웹앱 같은 디자인, PC 설명(0,8400,5000,1000)은 메인 외 모바일 같은 본문/상하단만PC/상세팝업모바일을 명시한다. 통계알림 보드(4800,1050,850,2400)·PC 탭에는 작은 초록 미읽음 점, 본문에는 초 단위22.07.19 17:00:03이 있다. 기본정보-m도 비활성 통계/알림 탭의 우상단 점을 보여준다.

- 같은 탭/작은 원 패턴으로 실제 본인 미읽음 수>0에만 점을 표시한다. 접근 가능한 링크 이름은 통계/알림 그대로 두고 별도 설명에 실제 수 또는 미확인/실패 안내를 둔다. 미확인·실패를0으로 발표하지 않는다.
- 페이지 진입에서만 최소 요약을 읽고 알림 목록/명시 확인·읽음/만료 확인의 실제 응답으로 갱신한다. 폴링·Realtime·별도 장기 캐시·전체 dashboard 새로고침을 만들지 않았다. Auth 신원/조회 세대/언마운트 가드로 이전 계정·늦은 요약이 새 읽음 결과를 덮지 않게 한다. 알림 목록도 신원 변경 뒤 응답을 폐기한다.
- 댓글/알림 공통 시각은 Asia/Seoul YY.MM.DD HH:mm:ss. 커서는 원래 서버 정밀 시각/ID를 사용하며 표시 시각으로 대체하지 않는다. 탈퇴 안내의 인증 계정은 렙타일링크 계정, 업로드 임대는 업로드 유효기간으로 명확히 했다. Google 계정 자체를 삭제한다는 의미가 아니다.
- 작은 활성 탭 글자는 같은 초록 계열#24853b로 어둡게 했고 키보드 초점은 기존 테두리를 재사용한다. 성장 선/점은 공통#178f3c로 통일해 흰 배경 대비를 보완한다. 공통 CSS가 React/Worker 양쪽에 적용된다. disabled 상태·제목/값·실제 기록/포인트·저장/초안 보호를 유지한다.

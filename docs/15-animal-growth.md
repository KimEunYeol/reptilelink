## 저장·권한

- `growth_records`는 소유자 복합 FK/CASCADE·날짜 고유 제약·소유자 인덱스와 RLS를 가진다. 일반 역할은 id/animal_id/measured_on/weight_g만 SELECT할 수 있고 직접 쓰기·소유자/내부 시각 조회를 허용하지 않는다. 공개 읽기는 모든 상위 공개·활성·성장 동의를 요구한다.
- `private.growth_notes`와 기존 `private.animal_notes`는 기록/개체 메모를 분리한다. 일반 테이블 권한과 공개 DTO에 메모를 포함하지 않는다. 개체의 실제 최종 삭제는 성장/메모도 cascade로 제거하고, 사진 정리 대기 동안에는 조회/새 수정이 차단된다.
- `save_animal_growth(id,data,expected,request_id)`는 upsert≤100/삭제 ID≤100·개체 메모·성장 공개 설정을 한 트랜잭션·한 revision/24시간 영수증으로 적용한다. 본문 필드/자료형·UUID·실제 날짜·양수/100000g/소수둘째 자리·기록 메모1000자/개체 메모2000자·활성/동의/소유권·살아 있는 개체·버전·최종 날짜 중복·계정당 실제3000행을 검사한다. 날짜 교환도 지연 고유 제약 아래 최종 상태를 검사한다.
- 무게는 십진 문자열로 보내며 DB도 정밀도 CHECK를 적용해 소수3자리의 자동 반올림을 방지한다. 메모는 공백을 임의로 지우지 않으며 Unicode 코드포인트 길이를 검증한다. 프로필 잠금으로 다른 개체의 동시 변경·한도·영수증을 직렬화한다. 다른 소유자/개체의 record ID 연결/삭제는 거절한다.
- 쓰기 중지 중에는 기존 기록 삭제·공개 끄기·메모 비우기를 허용한다. 추가/수정/새 공개/새 메모는 계속 차단한다. 실패는 기록/메모/공개/revision/영수증을 함께 롤백한다. 영수증에는 대상 ID/revision만 있고 메모/본문은 저장하지 않는다.

## 조회와 그래프

본인 `my_animal_growth`는 기록/메모·공개 설정·revision/개수와 서버 한국 날짜를 반환한다. 공개 `public_animal_growth`는 invoker/RLS에 더해 활성+프로필 공개+개체 공개+성장 동의+미삭제를 확인하며 비공개/없는 경우 NULL이다. 공개 DTO는 날짜/체중·범위·페이지 정보만 반환하며 소유자/사용량/메모/revision은 없다. 이미 전달된 정보는 회수할 수 없지만 공개 끄기 이후 새 조회는 거절한다.

주간/월간/년간은 한국 오늘을 포함한7/30/365일이다. 실제 날짜순 관측만 사용하며 빈 날짜 값을 생성하지 않는다. 최대120관측으로 실제 첫/마지막 날짜를 포함해 표본화한다. 전체 목록은 날짜 내림차순20건 커서 페이지이고 그래프 기간 전환은 이미 불러온 목록/초안을 지우지 않는다. 최신 체중은 그래프 기간과 독립적인 가장 최근 실제 기록이다. 그래프는 저장된 데이터 기준이라고 표시해 미저장 입력과 혼동하지 않는다. 축의 가로 위치도 실제 경과 날짜를 사용한다.

## 실패·취소·이동

확인된 초안만 저장하며 저장 전에는 DB/공개 데이터가 바뀌지 않는다. 취소는 초안을 버리고 실제 저장을 되돌려 쓰지 않는다. 응답 유실에는 같은 명령/요청 ID를 보존하고 입력/이동을 잠근다. 저장 후 dashboard 재조회가 실패해도 잠금을 풀지 않는다. 취소/최신 검토는 미확인 명령 재확인과 실제 조회가 성공해야 완료한다. 최신 기록 검토는 기존 입력을 바로 덮지 않고 복사/명시적 최신 기록 사용을 제공한다. 같은 요청 재전송은 새 revision을 만들지 않는다. 초기 조회 재시도도 동시에 겹치지 않게 한다.

첫 브라우저 실행에서 닫기 후 초점, 저장된 textarea의 명시적 라벨, PostgREST 오류 객체의 message 분류 문제를 확인해 보완했다. 정책/버전의 확정적 거절과 transport 실패를 구분해 쓰기 중지 중 취소/최신 검토도 가능하다. 실제 조회 실패의 잠금은 유지한다. SPA Back/Link와 전체 문서 이탈을 기존 보호 훅으로 처리한다.

## 로컬 검증·마이그레이션

신규 DB51개·단위6개·브라우저8개가 통과했다. DB는 날짜/정밀도/중복/3000한도·직접 권한·다른 계정/개체/비활성/동의·영수증/만료/경합/롤백·메모 격리·공개 조건·실제 날짜/최대120점/페이지·연관 삭제를 검증한다. 브라우저는 미저장 일반 편집 진입 잠금/취소/7개 폭·실제 저장/새로고침/공개 동의/메모 비노출·입력 경계·유실 재시도·실패 재조회/취소/이동 잠금·충돌 명시적 검토·기간/페이지/dirty Back·쓰기 중지 삭제/숨김/새 저장 거절을 포함한다. QA는 이번 실행에서 만든 개체/기록 ID만 정리하고 기존 개체의 전후 해시가 같다.

로컬 SQL로 반복 검증하고 타입/보안 advisors 경고 이상 없음, CLI migration new → 실제 db pull --local 출력의 `20261029060006_animal_growth.sql`·로컬 이력 일치·신규 migration까지 shadow 재현 후 db diff 차이 없음을 확인했다. 배열 초기화 타입 경고는 명시적 UUID[]로 보완했다. 기존 migration/schema snapshot 재적용·DB/볼륨 초기화·원격 프로젝트 변경은 없다.

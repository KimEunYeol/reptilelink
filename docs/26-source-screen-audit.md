원본 상세의 부·모 개체/입양일은 현재 F-03에 없는 명세 확장 대상이다. 범위 선택을 별도로 질의했으며 나머지 정비와 운영 준비는 독립 진행한다. 해당 관계를 다른 사진 슬롯으로 해석하거나 구현 완료라고 기록하지 않는다. 필드 추가 시 별도 명세/권한/마이그레이션/원본 검증이 필요하다.

실제 법적 문서·운영 주체/연락처·이미지/브랜드 배포 권리는 사용자 자료와 데스크톱 운영 준비가 필요하다. 원본 예시 회사/이메일/전화/주소/TEAM770·정책 본문을 실제 운영 정보로 복사하지 않는다. 고객센터가 아직 준비 상태이면 ‘제출 완료’나 답변 발송을 표시하지 않는다. Google/운영 Supabase/Cloudflare 콘솔·원격 OAuth/배포·도메인은 사용자 데스크톱 범위다.

## 자산과 접근성

원본 인벤토리는97 PNG다. 런타임 관리 로고/프로필 기본 자산은 public/brand/README.md의 원본/좌표/해시를 사용한다. App의 수제 Brand/Gecko는 메인·인증·공개 기본 표시에 남아 있어 교체 대상이다. 실제 사용자가 업로드한 사진·기존 fixture 바이트는 이 감사에서 변경하지 않았다. Group/Snippets는 대부분 댓글/언어/수치 말풍선 등 부분 자산이며 이름만 보고 히어로/로고라고 간주하지 않는다. 필요한 부분은 원본에서 결정적으로 추출해 출처를 기록하며 새 그림이나 전체 화면 PNG UI를 만들지 않는다.

원본의 정확한 폰트 파일/서체 확인 자료는 없다. CSS의 Pretendard/Noto 계열 목록이 원본 폰트 일치 증거는 아니다. fallback/굵기·줄바꿈·Native 날짜/종류 컨트롤 차이를 기록하고 원본 관계를 유지한다. 외부 폰트/브랜드 권리를 추정하지 않는다.

실제 관리 버튼의 흰 글자/초록(rgb44,187,80)은 약2.520687:1,390px에서12px/500·1440px에서14px/500이었다. [W3C 일반 글자4.5:1/큰 글자3:1](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html), [필수 UI/그래프3:1](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)을 기준으로 같은 계열/기존 패턴의 최소 보완을 검토한다. [320 CSS px 리플로](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)·키보드/초점·긴/빈/오류/disabled 상태를 화면별 검증한다. 현재390/1440의 넘침 없음만으로 전체 접근성/WCAG 준수를 선언하지 않는다.

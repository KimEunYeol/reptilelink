## 수집·개인정보

공개 프로필/유효한 개체 상세를 실제 표시한 탭이 무작위 UUID를 보낸다. UUID는 탭의 sessionStorage와 탭 메모리에만 두고 Auth 토큰·사용자 정보·입력을 추가로 저장하지 않는다. 저장소가 막히면 탭 메모리로 동작하며 새로고침 후 중복될 수 있다. 탭 복제/세션 초기화/봇 등에 따른 한계가 있는 참고 지표다. 소유자가 자기 공개 페이지를 열어도 같은 규칙을 쓴다.

Worker는 서비스 전용 analytics_target에서 내부 프로필/서버의 한국 날짜를 받고 HMAC-SHA256(v1 구분자·프로필·날짜·정규화한 UUID)을 계산한다. 원문 세션·IP·User-Agent·이동 경로를 통계 DB/앱 로그에 저장하지 않는다. 클라이언트가 만든 해시·날짜·역할을 받아 신뢰하지 않는다. 공개 응답은 수집 여부·서버 날짜·다음 날짜까지의 시간뿐이며 프로필 UUID·수치·해시·키는 반환하지 않는다. 제공업체 자체의 네트워크 로그/보관 정책을 앱이 없앴다고 주장하지 않는다.

동일 프로필/같은 한국 날짜/세션의 영수증은 한 건이다. 같은 탭의 새로고침/상세 이동·응답 유실 재요청도 증가시키지 않는다. 날짜가 바뀌는 사이 target 조회와 집계가 엇갈리면 새 서버 날짜로 한 번만 재확인한다. 브라우저 시계로 DB 날짜를 정하지 않는다. 공개 렌더링은 수집 결과를 기다리지 않으며 실패/중지/한도/키 누락이 본문·댓글·좋아요를 막지 않는다. 요청은2.5초로 제한하고 실패 뒤60초/성공 뒤 서버 날짜 경계까지 탭 메모리에서 반복을 줄인다. 자동 재시도/폴링은 없다.

POST JSON의 Origin/Content-Type·strict slug/UUID·8KiB 상한을 검사한다. Origin은 브라우저 출처 보호이며 봇 인증 장치가 아니다. CLI의 위조 Origin/새 세션 생성까지 막는다고 주장하지 않는다. 공개가 아닌/없는 주소는 동일한 수집 안 함 응답이다. 비공개/중지 전환과 수집은 실제 대상 계정/프로필 잠금으로 순서를 정한다.

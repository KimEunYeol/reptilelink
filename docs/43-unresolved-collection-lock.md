# 미확인 개체 목록 초안 잠금 (#71)

운영 준비의 전체 검사에서 만료된 목록 요청의 최신 조회가 실패한 뒤 공개 스위치가 활성인 결함을 확인했다. 기존 컨트롤은 busy만 검사하고 unresolved를 누락했다. 기존 회귀도 처리 중의 짧은 busy 상태만 보고 통과할 수 있었다.

## 변경과 보존한 흐름

busy/conflict/unresolved에서는 공개 스위치·위/아래·native drag와 change/move 핸들러를 잠근다. 제출 직후의 이벤트도 submitting ref로 거절한다. 일반 미저장 목록은 계속 편집하며, 미확인 상태에서는 같은 명령 재시도·취소의 실제 조회·최신 목록 확인과 명시적 선택을 사용할 수 있다. 실패한 조회와 단순 조회 성공은 편집 잠금을 풀지 않는다. 페이지별 조회·기존 안내/확인 UI·DB/RPC 계약은 유지한다.

## 원본 근거

원본 개체 관리 PC/m와 디자인 보드의 카드·화살표·하단 적용하기 구분, PC 공통 설명의 모바일 본문 패턴을 직접 확인했다. 기존 초록/회색 공개 스위치·disabled 패턴과 notice를 사용하며 새 화면·그림·배치가 없다. 원본97PNG·정확한 폰트/권리 확인의 미완료 상태는 이 변경으로 해소되지 않는다.

## 실제 검증

강화한2개체 회귀는 기존 코드에서 최신조회503의 처리가 끝난 뒤 스위치 활성으로 실패했다. 수정 뒤 같은 회귀가 통과했다. 스위치·정렬·draggable 상태와 원래 공개 초안·한 번의 명령, 최신 목록의 명시적 선택 후 해제를 확인한다. 기존 취소 회귀도 미확인 초안을 로컬에서 원복할 수 있다는 전제 대신 실제 동결·합성 클릭 거절·이동 잠금·성공한 취소 조회 후 해제를 검사한다.

표적 회귀의 기존 코드 실패→수정 후 통과, 관련 목록/영수증 24개 브라우저 검사(59.5초), 7폭 넘침 0과 동결 캡처를 확인했다. 고정 전체 검사는 최종 HEAD에서 별도로 실행하며 결과는 task71/PR·비공개 보고서를 따른다. 초기 실패 로그/trace는 `.local/collection-71`과 운영 준비 기록에 보존하며 성공으로 합산하지 않는다. 캡처는 ignored `artifacts/collection-71/frozen-{320,360,390,450,768,1440,1920}.png`다. 원격 Google OAuth·운영 정책/권리·공개 배포·원격 복구는 #62/#69에서 계속 미완료다.

# 메인 원본의 부분 예시 자산 (#37)

사용자가 제공한 design/메인화면.png·메인화면-m.png에서 휴대폰/개체·댓글/성장 그래프/일정/SNS 연결 그림 부분만 PNG로 추출했다. manifest.json은 각 파일의 원본 경로·원본 SHA256·사각형 좌표[left,top,width,height]·결과 SHA256·바이트 수를 기록한다. 원본 픽셀의 결정적 직사각형 추출이며 재그림/확대/색 변경 없이 원본을 보존했다. PC/모바일은 해당 원본에서 별도로 추출했고 reptiles-pc만 원본 공통 삽화로 축소 표시한다.

이 이미지는 모두 설명용 화면 예시다. 실사용자 프로필/사진/후기/조회수/실제 행사 일정으로 쓰지 않는다. 실제 제목·설명·가입/로그인/관리 이동·안내 링크는 접근 가능한 HTML이다. 전체 시안 PNG를 UI로 사용하지 않았으며 시안 하단의 회사/이메일/전화/주소/TEAM770은 반입하지 않았다. 캡션과 alt에 예시의 의미를 적었다.

외부 배포의 로고/예시 사진/폰트·브랜드 권리 확인은 완료되지 않았다. 현재 범위는 지시된 로컬/비공개 구현과 비교이며 실제 운영 자료·외부 배포는 데스크톱 준비 단계다.
